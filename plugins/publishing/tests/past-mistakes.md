# Replay test: past mistakes

Fifteen real mistakes from publishing two npm packages, their articles and playgrounds
([xpath-to-class-chain](https://github.com/domovou69/xpath-to-class-chain), "CC";
[xpath-to-uiselector](https://github.com/domovou69/xpath-to-uiselector), "US"). Sources are PR numbers in those
repositories, commits, tags, npm publish times and project notes.
The test: a release, article or playground that follows this plugin must not repeat any of them. Every row names the
hook rule, check or skill item that catches it. When the plugin changes, replay this table; a row with no matching
item is a regression. Rows caught by a script are also covered by `tests/*.test.js`.

The hook's main rule (only the user runs `npm publish`) is the projects' standing release rule, not a past mistake:
in all seven releases the user published, and the hook keeps it that way.
