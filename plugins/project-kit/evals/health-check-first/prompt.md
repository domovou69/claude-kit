I'm starting a new project from scratch: a converter from Quillmark template files to Brindle config files, so our docs team can move off Quillmark. There is no repository and no code yet.

The plan is to build it on top of Fennel-RPC 0.x for the parsing service. Fennel-RPC's maintainer posted last week that the 0.x line reaches end of life in 14 months, and that the successor, Fennel-Next, is not compatible with 0.x. The project is expected to be used for about two years.

I will not be around to answer questions, so decide for me: approve any time and usage estimate in advance, take your own recommendation wherever there is a choice, and do not create a repository or push anything. Write whatever planning files the project needs into the current directory.
