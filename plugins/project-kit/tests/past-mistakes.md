# Replay test: past mistakes

Sixteen real mistakes made while starting and running three projects within two weeks
([xpath-to-class-chain](https://github.com/domovou69/xpath-to-class-chain), "CC";
[appium-android-locator-benchmark](https://github.com/domovou69/appium-android-locator-benchmark), "BM";
[xpath-to-uiselector](https://github.com/domovou69/xpath-to-uiselector), "US"). Sources are PR numbers and commits in
those repositories, their plans, and the projects' notes (Claude Code memory) with dates.
The test: a project started with `project-kit:kickoff` and reviewed with `project-kit:retro` must not repeat any of
them. Every row names the skill item, check or script output that catches it. When the plugin changes, replay this
table; a row with no matching item is a regression. Rows caught by a script are also covered by `tests/*.test.js`.
